## Why Holtdroid

<CardGrid stagger>
  <Card title="No APK patching" icon="approve-check">
    WebView remote debugging is switched on at runtime. The APK is installed exactly as your team shipped it.
  </Card>
  <Card title="Everything in one tab" icon="laptop">
    Device screen and Chrome DevTools side by side, with a target switcher and two-way clipboard. No adb or local Chrome
    needed.
  </Card>
  <Card title="ARM APKs on x86 nodes" icon="rocket">
    Android in containers on the node's kernel (redroid), several per node, with ARM translation for ARM-only builds.
  </Card>
  <Card title="Per-session VPN" icon="random">
    Each device gets its own egress. Switch the country from the network card next to the device without restarting
    anything.
  </Card>
  <Card title="Sessions that clean up" icon="seti:clock">
    Bounded slots, idle timeout and max TTL. See who is using what, extend with one click.
  </Card>
  <Card title="Pluggable by contract" icon="puzzle">
    Artifact sources, device providers, VPN vendors, secret backends and auth are swappable. Real phones on USB work
    too, without root.
  </Card>
</CardGrid>

## How it fits together

A build travels from wherever your team posts it to a device that only you are using, and the device comes to your
browser. Each step lives in its own repository.

## Try it

<Tabs>
  <TabItem label="On your laptop" icon="laptop">
    Simulated devices, no cluster and no KVM: enough to click through the whole UI.

    ```sh
    git clone https://github.com/holtdroid/holtdroid && cd holtdroid
    mise install
    make dev    # http://localhost:8080, APKs from internal/apk/testdata
    ```

    More in [Local development](/holtdroid/start/local-development/).

  </TabItem>
  <TabItem label="On Kubernetes" icon="rocket">
    One Helm chart; nodes with binder run the Android containers.

    ```sh
    helm install holtdroid oci://ghcr.io/holtdroid/charts/holtdroid -n holtdroid -f values.yaml
    ```

    What goes into `values.yaml` is in [Installation](/holtdroid/start/installation/).

  </TabItem>
</Tabs>
