## Try it

<div class="hd-split">
<div>

Start on your laptop with simulated devices: no cluster and no KVM, enough to click through the whole UI. When it
fits, install the Helm chart on a cluster whose nodes run the Android containers.

- [Local development](/holtdroid/start/local-development/)
- [Installation](/holtdroid/start/installation/)
- [Architecture](/holtdroid/concepts/architecture/)

Holtdroid is **pre-alpha** and built in the open: anything may change until the first tagged release. Follow the
[roadmap](https://github.com/holtdroid/holtdroid/blob/main/design/roadmap.md).

</div>
<div>

<Tabs>
  <TabItem label="On your laptop" icon="laptop">

    ```sh
    git clone https://github.com/holtdroid/holtdroid && cd holtdroid
    mise install
    make dev    # http://localhost:8080 with simulated devices
    ```

  </TabItem>
  <TabItem label="On Kubernetes" icon="rocket">

    ```sh
    helm install holtdroid oci://ghcr.io/holtdroid/charts/holtdroid -n holtdroid -f values.yaml
    ```

  </TabItem>
</Tabs>
