## Что происходит

**Logcat** — это системный журнал Android: приложения и система пишут в него, что делают, а при крэше там
остаётся полный текст ошибки.

1. Приложение <Hint to="phone-buy" step={1}>падает</Hint>: Android показывает на экране «keeps stopping».
2. Holtdroid это замечает и показывает <Hint to="toast" step={2}>уведомление</Hint> с первыми строками ошибки.
   Нажмите в нём <Hint to="toast-action" step={3}>Logcat</Hint>.
3. Откроется вкладка Logcat. <Hint to="log-exception" step={4}>Красные строки</Hint> — это ошибки: имя исключения,
   его сообщение и строки, начинающиеся с `at`, показывают, где в коде это случилось.
4. Сузьте поиск: <Hint to="log-scope" step={5}>This app / Everything</Hint> переключает между строками вашего
   приложения и всего устройства, фильтр <Hint to="log-level" step={6}>уровня</Hint> оставляет только ошибки,
   а текстовое поле ищет тег или слово.
5. <Hint to="log-download" step={7}>Download</Hint>
   сохраняет то, что сейчас показано, — готовый файл для тикета.
6. После крэша приложение остаётся закрытым. <Hint to="app-restart" step={9}>Restart app</Hint> в карточке App
   запускает его снова.

## Полезно знать

- Журнал собирается с момента, когда устройство готово, и не теряется при перезапуске приложения и установке
  другой сборки. Крэш десятиминутной давности тоже можно найти.
- **This app** следит за вашим приложением по его user id, поэтому видит все его процессы и не теряет их после
  перезапуска.
- Для баг-репорта со всем сразу (скриншот, журнал, сведения об устройстве) есть кнопка **Bundle** в карточке
  Device.

## Если не работает

- **Уведомление не появилось**: приложение могло закрыться без крэша, например само вызвало `finish()` или его
  убила система из-за памяти. Посмотрите Logcat в режиме **Everything** с уровнем **Error**.
- **Вкладки Logcat нет или она чего-то ждёт**: вкладка работает через ADB устройства, а в чужой сессии он вам
  недоступен.
- **Ошибка в веб-части приложения** (белый экран, не работает кнопка): смотрите
  [консоль DevTools](/holtdroid/ru/guides/web/devtools/); ошибки JavaScript не роняют Android-приложение.

Подробнее: [Logcat](/holtdroid/ru/session-tools/logcat/), [ADB tools](/holtdroid/ru/concepts/adb/).
