**Зачем:** вы делаете веб-часть приложения на ноутбуке и хотите увидеть её внутри WebView настоящего приложения на
настоящем Android, ничего не выкладывая на сервер.

<Guide id="local-server" />

## Что происходит

1. Сначала [подключите свой компьютер](/holtdroid/ru/guides/developers/connect-computer/) и не закрывайте клиент
   `holtdroid`.
2. <Hint to="terminal" step={1}>
     Запустите dev-сервер
   </Hint>
   как обычно, например Vite на порту 5173.
3. Порт появится на странице Computers. <Hint to="port-5173" step={3}>Кликните по нему</Hint>, чтобы опубликовать
   его на своих устройствах; в режиме **Dev servers** (он по умолчанию) клиент публикует серверы вроде `node`,
   `bun` или `vite` сам.
4. На странице сессии <Hint to="w-ssh" step={6}>карточка SSH</Hint> показывает
   <Hint to="ssh-port-5173" step={7}>
     опубликованные порты
   </Hint>
   .
5. Откройте на телефоне <Hint to="phone" step={8}>`http://localhost:5173`</Hint>: страница приходит с вашего
   ноутбука.

## Полезно знать

- Порт — это «номер двери», на которой программа ждёт подключений: dev-сервер слушает 5173, поэтому он
  `localhost:5173`. Публикация открывает такую же дверь на устройстве.
- Опубликованный порт попадает на все ваши устройства, включая те, что вы запустите позже, и только на ваши.
- Обычный `http://localhost` работает, даже если приложение запрещает незашифрованный трафик: для localhost Android
  делает исключение. Остальные адреса подчиняются правилам приложения.
- Горячая перезагрузка работает: сохранили файл — страница на телефоне обновилась.
- В режиме **Everything** публикуется всё, что слушает порты на вашем компьютере, включая обычные программы.
  Клиент спрашивает, прежде чем включить этот режим.

## Если не работает

- **Порта нет на странице Computers**: проверьте, что клиент запущен, а сервер слушает `localhost`, а не только
  какой-то другой адрес.
- **Порт в карточке SSH красный**: на этом порту вашего компьютера никто не отвечает. Запустите сервер или
  проверьте номер.
- **Страница открывается, но запросы к API падают**: приложение всё ещё ходит в API по обычному адресу. Направьте и
  его на `localhost` или опубликуйте ещё и порт API.
- **На эмуляторе порт пропускается**: несколько портов заняты самой сессией (5555, 5038, 27042, 18580, 18581, 7890,
  9090). Возьмите другой.

Подробнее: [Connecting your computer](/holtdroid/ru/concepts/ssh/).
