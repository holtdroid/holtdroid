**Зачем:** во многих приложениях часть экранов — это веб-страницы. Когда там что-то ломается, DevTools показывает,
какой запрос упал и какую ошибку выдала страница, и в баг-репорте будет написано, что именно сломалось, а не
просто «не работает».

<Guide id="devtools" />

## Что происходит

1. Вкладка <Hint to="tab-devtools" step={1}>DevTools</Hint> находится рядом с телефоном. Это инструменты
   разработчика Chrome, подключённые к **WebView** приложения — встроенному браузерному движку, который показывает
   веб-страницы внутри приложений.
2. <Hint to="dt-network" step={2}>Network</Hint>
   показывает все запросы страницы. <Hint to="req-cart" step={3}>Красная строка</Hint>
   — запрос с ошибкой; нажмите на неё, чтобы прочитать <Hint to="req-details" step={4}>заголовки и ответ</Hint>.
3. <Hint to="dt-console" step={5}>Console</Hint>
   показывает сообщения страницы и <Hint to="console-error" step={6}>ошибки</Hint>
   с файлом и строкой, откуда они пришли.
4. <Hint to="dt-elements" step={7}>Elements</Hint>
   показывает HTML и стили — для багов вёрстки.
5. Продолжайте пользоваться <Hint to="phone" step={8}>телефоном</Hint>: всё новое появляется сразу.

## Полезно знать

- Holtdroid включает отладку WebView при старте приложения. APK не меняется и не пересобирается.
- В строке над DevTools виден адрес страницы. Введите другой адрес и нажмите Enter, чтобы открыть его в WebView;
  кнопка слева перезагружает страницу.
- Если в приложении несколько веб-страниц или процессов, выберите нужную в списке целей рядом с адресом.
- Iframe (страница внутри страницы) не отдельная цель: откройте Console и выберите его в меню `top ▾` в левом
  верхнем углу консоли.

## Если не работает

- **DevTools пустой, «Waiting for a WebView…»**: на текущем экране приложения нет веб-содержимого. Откройте ту
  часть приложения, где оно есть.
- **На настоящем телефоне DevTools пустой**: на телефоне без root свои WebView показывают только отладочные
  (debug) сборки. Попросите debug-сборку или используйте виртуальное устройство.
- **Приложение закрывается сразу после старта**: некоторые приложения отказываются работать на рутованных или
  эмулированных устройствах. Попробуйте настоящий телефон.
